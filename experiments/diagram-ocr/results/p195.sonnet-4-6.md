# claude-sonnet-4-6 — p195 (Fig 11.2 EAR/SDI waveform, timing diagram)

## 1. Faithful transcription
Prose: "Input wave from EAR Pin is reformed to Square wave and sent to SDI Pin
of 80C85 as shown blow. The input wave is inverted on the way to SDI Pin from
EAR Pin. In reading operation, the electric high/low level has no meaning. The
pulse frequency indicate whether high or low of the data. The frequency, 2400Hz
means logical high, and the frequency, 1200Hz means low."

Figure: signals `EAR` / `SDI`; spans `<-- MARK -->` then `<--- SPACE --->`;
`2400Hz` under MARK, `1200Hz` under SPACE. Caption `Fig 11.2`.

## 2. Best representation
Mermaid has no timing-waveform primitive; sequence/gantt can't render a labeled
square-wave. **Recommendation: keep a faithful ASCII-art code block** (the source
is already ASCII), optionally with the cropped page image as backup.

```text
EAR -----      |<-- MARK --->|<--- SPACE ----->|
            -+ +-+ +-+ +-+  +----+  +---+  +----
SDI -----   | | | | | | | |  |    |  |   |  |   |
            +-+ +-+ +-+ +-+  +----+  +---+  +---+
               2400Hz           1200Hz
```

## 3. Key facts table
| Region | Frequency | Logical value |
|--------|-----------|---------------|
| MARK   | 2400 Hz   | High (1)      |
| SPACE  | 1200 Hz   | Low (0)       |

EAR→SDI inverts the level, but data is encoded purely in pulse frequency.
